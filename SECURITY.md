# Security Policy

## Scope

Agent X-Ray is a static configuration review aid. It is not a runtime protection system and its findings do not prove exploitability.

## Reporting a vulnerability

Please do not open a public issue containing live credentials, private customer data, or exploitable details against a third-party system. Open a private security advisory in the repository where available, or contact the maintainers through a private channel.

Include the affected version, a minimal sanitized reproduction, expected impact, and suggested mitigation. Never include real tokens or secrets; use synthetic values.

## Supported versions

Security fixes are currently targeted at the latest main branch.
